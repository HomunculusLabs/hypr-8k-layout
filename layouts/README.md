Layouts
=======

This folder contains custom Hyprland layout systems and their scripts.

Contents
--------
- centerstage: Primary ultrawide 3-zone layout (workspaces 1-3)
- triad: Standalone 3-zone layout for workspace 2

Notes
-----
- Centerstage scripts and docs live under hypr/layouts/centerstage/.
- Triad scripts and docs live under hypr/layouts/triad/.
- Hyprland bindings and autostart reference these paths.

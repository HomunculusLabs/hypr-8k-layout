KEYBOARD-FIRST HYPRLAND / CENTERSTAGE

Everyday controls
  Super + H/J/K/L          Focus left/down/up/right
  Super + Shift + H/L      Move through Centerstage zones/subcolumns
  Super + Shift + J/K      Reorder down/up within the current zone
  Super + P               Move focused window to center
  Super + Tab             Toggle to previous window (across workspaces)
  Super + W               Search open windows by app/title/workspace
  Super + /               Search shortcut reference (does not execute entries)
  Super + Space           Application launcher
  Super + 1..9            Switch workspace
  Super + Shift + 1..9    Move window to workspace
  Ctrl + Shift + 4         Select screenshot region and copy to clipboard

Movement uses Centerstage scripts only for zone-tagged windows on workspaces
1-3. Other windows use native Hyprland movement. Existing Centerstage arrow,
bracket, punctuation, and numbered focus shortcuts remain available.

Centerstage adjustment mode
  Press Super + R, then RELEASE the modifiers.
  W                       Cycle center width preset
  T or J                  Cycle center height preset
  B                       Cycle sidebar balance
  L                       Cycle left sidebar layout
  H / K                   Shrink / expand left primary column
  A                       Toggle sidebar auto-shrink
  S                       Save layout
  Escape or Enter         Exit adjustment mode
  Super + R               Also exits adjustment mode

Adjustments take effect immediately. Escape exits; it does not undo them.
While in adjustment mode, normal global bindings are not active.
Use this mode for Centerstage layouts, not native workspaces.
No keyboard firmware, thumb cluster, or modifier remapping was changed.

Configuration
  ~/.config/hypr/bindings.lua
  ~/.config/hypr/scripts/keyboard-navigation.py
